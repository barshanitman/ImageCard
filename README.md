# Deck of Cards Classification (For Practise)  

Testing out the capabilities of the Apple M1 Macbook PRO for Deep Learning.

Dataset from: https://www.kaggle.com/datasets/gpiosenka/cards-image-datasetclassification 

## Steps 

1. Download dataset from the source above 
2. Create a data directory in root of project and unzip dataset inside that directory
3. Run train.py 
4. Run inference.py and pass in path of image: python3 inference.py path_to_image
